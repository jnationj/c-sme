        Why this instead of asking a chatbot?

        • Current platform data, not memory. A chatbot answers from training data or whatever web pages it can open. We buy TikTok and Instagram data for your question from paid data providers.
        • Every claim has a receipt. The report lists each data call with its on-chain transaction, so you can check what it was built from.
        • Price first, cents per question. No subscription. You see the total, for example $0.04, before anything is paid.
        • It tells you what it doesn't know. Each report ends with what the data can't answer, and the agent can't spend past hard limits.

            Kept safe by design

            • The AI writes. A rules engine, not the AI, approves every payment.
            • Hard caps: per call, per report, per day.
            • Only approved providers and tokens.
            • Never pays twice. Stops if a payment is uncertain.
            • You pay only if the report is delivered. Your payment is authorised first but settles only after the report exists. If the data can't be bought, nothing is taken from you.
            • Every payment is logged with its transaction link.
